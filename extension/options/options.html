Higher effort thinks longer: more accurate on hard questions, slower and costlier.

Haiku 4.5 ignores the effort setting (the API rejects it) and has no adaptive thinking. It only reasons step by step when extended thinking is turned on here, with a fixed token budget shared by all questions on the page. Higher budgets help with calculations and cost more output tokens.

Needed for questions about a passage, table or code on the page. Turn off to send only the questions.

Used for questions about yourself. Leave empty and those boxes are skipped.

Diagnostics

Records, for each question, the detected text and choices, what was sent to Claude, the raw response (including thinking), how the answer was parsed, which page element it mapped to and what was done. Adds a Debug section to each answer badge and an Export button in the popup. It doesn't change the request or how answers are filled. Your API key is never included.

View it from chrome://extensions → PumpkinEater → "service worker". The API key is never logged.
